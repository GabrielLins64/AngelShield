CONFIGURAÇÃO AVANÇADA

Configurar Integração com Google

Configure as credenciais do seu projeto Google Cloud e o nome da pasta dos backups. Salve e use Conectar conta Google nesta janela para autorizar o acesso.

Como configurar no Google Cloud

Se aparecer “Que dados você acessará?”, escolha Dados do usuário. O backup fica no Drive da conta que você autorizar. Você precisa apenas de Client ID e Client Secret.

  1. No Google Cloud Console, abra o seletor de projetos no topo, clique em Novo projeto, dê um nome e selecione o projeto criado.
  2. Em APIs e serviços → Biblioteca, pesquise Google Drive API e clique em Ativar. Se o console permitir, siga sem cadastrar faturamento. Se exigir uma conta de faturamento, confira os preços e associe a conta em Faturamento → Meus projetos.
  3. Na Plataforma de autenticação do Google → Branding, informe o nome AngelShield e seu e-mail. Para Gmail pessoal, escolha público Externo. Em Público-alvo → Usuários de teste, adicione o e-mail que usará o Drive.
  4. Em Acesso a dados, adicione a permissão https://www.googleapis.com/auth/drive.file e salve.
  5. Em Clientes → Criar cliente, escolha Aplicativo da Web. Nas URIs de redirecionamento autorizadas, cole o endereço completo do campo Redirecionamento para cadastrar no Google Cloud abaixo, incluindo /google. As origens JavaScript podem ficar vazias para este fluxo.
  6. Crie o cliente e copie o Client ID e o Client Secret para os campos abaixo. Copie o segredo completo agora, pois ele só é mostrado integralmente na criação.
  7. Em Nome da pasta, mantenha AngelShield ou informe outro nome. Clique em Salvar configuração e depois em Conectar conta Google nesta janela. Escolha a conta de teste e autorize o acesso. Feche a configuração e use Exportar para o Drive para criar a pasta, se necessário, e o backup após sua confirmação.

No modo Em teste, o Google exige nova autorização após sete dias para este acesso ao Drive. Use Conectar conta Google novamente quando necessário.

As credenciais e a autorização salva ficam neste navegador. Ao abrir as configurações, o AngelShield verifica a conexão e pode renovar o acesso salvo. Os backups só são importados ou exportados quando você solicitar. Use o mesmo projeto Google Cloud nas instalações que compartilharão o histórico.

Deixe Client Secret vazio para manter o valor salvo. O AngelShield usa a pasta com o nome informado e a cria no primeiro envio, se necessário. Nenhum salt ou chave do cofre é enviado ao Google.
